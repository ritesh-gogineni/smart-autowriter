# Featured photo policy

A new post needs a featured image that you are licensed to use. This matters more than any other rule here: agencies pursue unlicensed use with large invoices.

NEVER download images from news sites, Google Images, company or organisation websites, or social media. NEVER reuse an image from the site's own media library except through the search command in step 1: older uploads with no credit have unknown licences.

Order of preference; stop at the first good one:
1. **The site's own pre-cleared library** (only if the config uses the WordPress backend and a media index was built). Run `python3 <autowriter.py> media <words>`, for example a name plus an organisation or place, then the full name, then the broader subject. It searches the alt text, title and caption of images already classified as wikimedia_cc (Creative Commons), stock_free (Unsplash, Pixabay, Pexels) or ai_illustration. Results rank by number of matching terms, then by kind, then by date. Do not trust alt text blindly: download each shortlisted url, LOOK at it with the Read tool, and reject blurry, badly lit, crowd shots or the wrong subject. Prefer a photo that was not used on the last few posts about the same subject.
   If you pick a library photo: write image.json `{"source":"library","existing_media_id":<id>,"alt_text":<fresh description>,"caption":<library caption>,"artist","licence","commons_url"}` and also save a 1200x675 JPEG copy as `RUN/image.jpg`. End draft.html with a credit line built from the caption: for Commons images `<p><small>Featured photo: <artist>, <a href="<file page>" target="_blank" rel="noopener">Wikimedia Commons</a>, <licence> (cropped).</small></p>`; for stock `<p><small>Featured photo: <name> on <Unsplash|Pixabay|Pexels>.</small></p>`.
2. **Wikimedia Commons.** API: `curl -s -A 'YourBot/1.0 (https://your-site)' 'https://commons.wikimedia.org/w/api.php?action=query&format=json&generator=search&gsrnamespace=6&gsrsearch=<url-encoded name>&gsrlimit=20&prop=imageinfo&iiprop=url|size|extmetadata&iiurlwidth=800&iiextmetadatafilter=LicenseShortName|Artist|DateTimeOriginal|ImageDescription'`. Try 2-4 queries. Commons rate-limits parallel use (HTTP 429): wait 30-60 seconds, retry, and fetch the 1920px thumbnail instead of the original.
   Accept only CC BY (any version), CC BY-SA (any version), CC0 and Public domain. Reject anything else, including 'fair use' and non-free files. Shortlist 3-5, prefer the subject clearly in frame and in focus, recent, original width at least 1200px, landscape or croppable to landscape. Download each, LOOK at it, and reject blurry, tiny, badly lit or misidentified images.
   Crop to 16:9 framed on the subject, resize to 1200x675 with Pillow, save as JPEG quality 85 to `RUN/image.jpg`. No text overlays on photos. Write image.json `{"source":"commons","alt_text","caption":"Photo: <Artist> / Wikimedia Commons, <licence>","artist","licence","commons_url"}` and end draft.html with the credit line shown above.
3. **A generated graphic** when nothing suitable exists: a 1200x675 image with a solid background, large bold headline text and the site name bottom-right. Save as `RUN/image.jpg`, write image.json `{"source":"generated"}` and say so in your final message.

Scratch downloads go in `RUN/work/`.
